В файле settings.txt ввести креды от FineBI в формате логин:пароль

В файл list of colors ввести список цветов и категорий (для каждого отдельный столбец). Заголовок не трогать

В файл list of components ввести список компонентов, на которых нужно изменить цвета. Во втором столбце опционально указывается название индикатора, для которого изменяются цвета, если в окне Graphic Property индикаторов несколько. Заголовок не трогать

Запускать локально - серверный режим не поддерживается. Для работы необходим установленный Chrome.
